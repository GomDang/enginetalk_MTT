다른 작업자의 EngineTALK, 또는 PC의 EngineNOTE로 보냅니다. 카카오톡·메일·파일 앱으로 공유할 수 있습니다.

GitHub 기준 파일

이 폰에 쌓인 측정을 baseline.engineear 파일로 만듭니다. 이 파일을 GitHub 저장소의 index.html 옆에 올려 두면, 앱을 새로 열거나 저장 공간이 비었을 때 자동으로 불러와 기준이 이어집니다. 공개 저장소용이라 측정자 이름·의견·정비 내용 글·위도와 경도는 빠지고(장소 이름(지상/지하)·동 이름·날씨는 남음), 사운드도 넣지 않습니다.

확인 중…

아이폰은 오래 열지 않으면 브라우저 데이터를 지울 수 있습니다. 홈 화면에 추가하고, 정기적으로 보내기로 백업하세요.

도움말 · 녹음 요령

폰에서 여는 방법

마이크는 https:// 주소에서만 켜집니다. 파일 앱이나 카톡에서 이 HTML 파일을 바로 열면 녹음이 안 됩니다. https 주소(예: GitHub Pages)에 올려 두고, 사파리·크롬에서 연 뒤 홈 화면에 추가하세요.

원음 그대로 녹음

이 앱은 에코 제거·소음 억제·자동 음량 조절을 끄도록 요청하고, 압축하지 않은 WAV(16-bit)로 저장합니다. 폰 기종에 따라 일부 처리가 꺼지지 않을 수 있어, 측정 상세에 실제 적용 상태를 기록합니다.

클리핑은 편집이 아니라 소리가 마이크 한계를 넘어 잘리는 현상입니다. 측정 중 음량 막대가 빨갛게 되면 폰을 엔진에서 조금 멀리 두세요.

측정 세 가지

홈에서 지금 상황에 맞는 버튼을 누릅니다. 공회전 측정은 공회전(계기판 약 1000, 실측 약 910 rpm), 작업 RPM 측정은 작업 rpm(실측 약 2300), 시동 측정은 키를 돌리기 전에 시작해 시동이 걸리고 안정될 때까지 녹음합니다. 공회전과 작업은 각각 따로 20~30초씩 녹음하세요.

앱은 고른 상황의 rpm 범위(공회전 840~1000, 작업 2100~2500)에서만 rpm을 찾습니다. 그래서 다른 rpm의 줄에 끌려 숫자가 튀지 않습니다. 소리가 그 범위의 엔진 소리로 보이지 않으면 숫자 대신 "범위 밖"이 나오고, 측정의 절반 이상이 범위 밖이거나 중앙값이 기준에서 8% 넘게 벗어나면 그 측정은 기준(최근 10회)에서 자동으로 빠집니다. 이동 준비처럼 rpm이 정해지지 않은 상태는 지금 버전에서는 측정하지 않습니다.

경적이 울리면 앱이 알아채고 그 순간과 뒤 약 1초는 rpm과 소리 평균 계산에서 뺍니다(화면에 "경적 · 분석 제외"). 녹음 파일에는 그대로 남습니다.

시동 측정은 이번 버전에서 녹음과 저장만 하고 rpm 비교는 하지 않습니다. 시동 분석 화면은 다음 버전에서 만듭니다.

녹음 요령

폰 방향: 폰을 눕혀 화면은 위로, 아래쪽(아이폰 USB-C 단자, 마이크가 있는 쪽)을 엔진 쪽으로 향하게 듭니다. 화면을 보면서도 음성메모 때와 같은 방향이 됩니다. 마이크가 땅을 향하면 엔진 소리가 약해지고 바닥 반사음이 섞여, 원형 막대 모양이 기준과 달라집니다.

엔진 블록에서 50 cm~1 m, 매번 같은 자리·같은 방향. 냉각팬 바로 앞, 배기구, 에어밸브 배기구 근처는 피합니다. 측정 중 화면을 끄거나 다른 앱으로 가면 녹음이 끊길 수 있습니다. 작업 모드 W는 유압 ON, 일반 N은 유압 OFF를 뜻합니다.

기준은 어디서 오나요

기준은 같은 측정(공회전 / 작업 RPM)과 같은 작업 모드(N 일반 / W 작업)의 최근 10회 측정입니다. v0.5.0까지 앱으로 녹음한 측정은 상황 구분이 없어서 기준에 넣지 않습니다. 앱에는 2026-10-07~10-15에 분석한 녹음 7회의 rpm 값이 들어 있어서, 이 폰에 기록이 없어도 처음부터 비교를 시작합니다. 새 측정이 쌓이면 오래된 것부터 최근 10회에서 빠집니다.

원형 막대의 회색 평균(소리 모양)은 이 앱으로 녹음한 측정에서만 만들어집니다. 예전 분석 자료에는 이 값이 없어서, 이 폰이나 기준 파일에 앱 측정이 생긴 뒤부터 회색 막대가 나타납니다.

다시 열었더니 기록이 없어졌을 때

기록은 GitHub가 아니라 이 폰의 브라우저에 저장됩니다. GitHub에 새 index.html을 올리는 것만으로는 지워지지 않습니다. 대신 이럴 때 비어 보입니다.

· 아이폰에서 홈 화면 아이콘을 지우고 다시 추가한 경우 (아이콘마다 저장 공간이 따로라서, 아이콘을 지우면 기록도 지워집니다)
· 홈 화면 아이콘과 사파리 탭을 번갈아 연 경우
· 저장소 주소(사용자 이름)가 바뀐 경우, 개인 정보 보호 브라우징, 사파리 방문 기록·웹사이트 데이터 지우기

새 버전을 올린 뒤에는 아이콘을 다시 만들지 말고, 앱을 완전히 닫았다가 같은 아이콘으로 다시 여세요. 그리고 가끔 기준 파일 만들기로 GitHub에 올려 두면, 기록이 비어도 기준이 자동으로 돌아옵니다.

위치 · 날씨

측정을 시작하면 앱이 GPS로 위치를 잡고, 측정 시각의 기온·체감 온도·습도·풍속과 지난 24시간·96시간 최저 기온을 가져와 측정 기록에 넣습니다.

차량기지(지상): GPS가 잡히고 목록의 차량기지 2 km 안이면 그 차량기지를 자동으로 고릅니다. 날씨는 목록의 차량기지 좌표로 가져와 매번 같은 지점과 비교됩니다.

지하 본선: GPS를 쓸 수 없거나 위치 오차가 200 m보다 크면 "GPS 정보를 사용할 수 없습니다. 현재 위치를 선택해주세요"와 함께 장소 목록이 나옵니다. 고른 장소의 좌표로 날씨를 가져옵니다. 지하 측정의 기온은 터널이 아니라 바깥 공기(참고)입니다.

목록에 없는 곳은 이름을 입력하세요. 지상이면 GPS로 날씨를 가져오고, GPS가 안 되면 날씨 없이 저장합니다. 자동으로 고른 장소가 틀리면 "장소 바꾸기"를 누르세요.

날씨는 Open-Meteo(기상청 KMA 모델)에서 가져오며, 관측소 실측이 아니라 약 1.5 km 격자 값입니다. 체감 온도는 기상청 방식(5~9월 여름철 식, 그 밖에는 겨울철 식)으로 계산합니다. 인터넷이 안 되면 다음에 앱을 열 때 측정 시각 기준으로 다시 채웁니다. GitHub 기준 파일에는 위도·경도를 넣지 않습니다.

측정 화면의 원형 막대

원 둘레의 막대는 주파수 대역별 소리 크기입니다. 12시(40 Hz)에서 시작해 시계 방향으로 높은 소리(12 kHz)까지 갑니다. 1시~6시는 엔진 본체 소리, 6시 이후는 베어링·누설 같은 이상음 영역입니다.

회색 막대는 같은 운전 영역(공회전 또는 작업)의 최근 10회 평균, 흰 막대는 지금 소리입니다. 평균보다 6 dB 이상 크면 노랑, 10 dB 이상이면 빨강으로 바뀝니다. 원 가운데의 "평균과 일치"는 두 모양이 얼마나 닮았는지를 보여주는 참고값입니다.
