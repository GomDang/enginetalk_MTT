GitHub 기준 파일

이 폰에 쌓인 측정을 baseline.engineear 파일로 만듭니다. 이 파일을 GitHub 저장소의 index.html 옆에 올려 두면, 앱을 새로 열거나 저장 공간이 비었을 때 자동으로 불러와 기준이 이어집니다. 공개 저장소용이라 측정자 이름·의견·정비 내용 글은 빠지고, 사운드도 넣지 않습니다.

확인 중…

아이폰은 오래 열지 않으면 브라우저 데이터를 지울 수 있습니다. 홈 화면에 추가하고, 정기적으로 보내기로 백업하세요.

도움말 · 녹음 요령

폰에서 여는 방법

마이크는 https:// 주소에서만 켜집니다. 파일 앱이나 카톡에서 이 HTML 파일을 바로 열면 녹음이 안 됩니다. https 주소(예: GitHub Pages)에 올려 두고, 사파리·크롬에서 연 뒤 홈 화면에 추가하세요.

원음 그대로 녹음

이 앱은 에코 제거·소음 억제·자동 음량 조절을 끄도록 요청하고, 압축하지 않은 WAV(16-bit)로 저장합니다. 폰 기종에 따라 일부 처리가 꺼지지 않을 수 있어, 측정 상세에 실제 적용 상태를 기록합니다.

클리핑은 편집이 아니라 소리가 마이크 한계를 넘어 잘리는 현상입니다. 측정 중 음량 막대가 빨갛게 되면 폰을 엔진에서 조금 멀리 두세요.

녹음 요령

엔진 블록에서 50 cm~1 m, 매번 같은 자리·같은 방향. 냉각팬 바로 앞, 배기구, 에어밸브 배기구 근처는 피합니다. 측정 중 화면을 끄거나 다른 앱으로 가면 녹음이 끊길 수 있습니다. 작업 모드 W는 유압 ON, 일반 N은 유압 OFF를 뜻합니다.

기준은 어디서 오나요

기준은 같은 작업 모드(N 일반 / W 작업)의 최근 10회 측정입니다. 앱에는 2026-10-07~10-15에 분석한 녹음 7회의 rpm 값이 들어 있어서, 이 폰에 기록이 없어도 처음부터 비교를 시작합니다. 새 측정이 쌓이면 오래된 것부터 최근 10회에서 빠집니다.

원형 막대의 회색 평균(소리 모양)은 이 앱으로 녹음한 측정에서만 만들어집니다. 예전 분석 자료에는 이 값이 없어서, 이 폰이나 기준 파일에 앱 측정이 생긴 뒤부터 회색 막대가 나타납니다.

다시 열었더니 기록이 없어졌을 때

기록은 GitHub가 아니라 이 폰의 브라우저에 저장됩니다. GitHub에 새 index.html을 올리는 것만으로는 지워지지 않습니다. 대신 이럴 때 비어 보입니다.

· 아이폰에서 홈 화면 아이콘을 지우고 다시 추가한 경우 (아이콘마다 저장 공간이 따로라서, 아이콘을 지우면 기록도 지워집니다)
· 홈 화면 아이콘과 사파리 탭을 번갈아 연 경우
· 저장소 주소(사용자 이름)가 바뀐 경우, 개인 정보 보호 브라우징, 사파리 방문 기록·웹사이트 데이터 지우기

새 버전을 올린 뒤에는 아이콘을 다시 만들지 말고, 앱을 완전히 닫았다가 같은 아이콘으로 다시 여세요. 그리고 가끔 기준 파일 만들기로 GitHub에 올려 두면, 기록이 비어도 기준이 자동으로 돌아옵니다.

측정 화면의 원형 막대

원 둘레의 막대는 주파수 대역별 소리 크기입니다. 12시(40 Hz)에서 시작해 시계 방향으로 높은 소리(12 kHz)까지 갑니다. 1시~6시는 엔진 본체 소리, 6시 이후는 베어링·누설 같은 이상음 영역입니다.

회색 막대는 같은 운전 영역(공회전 또는 작업)의 최근 10회 평균, 흰 막대는 지금 소리입니다. 평균보다 6 dB 이상 크면 노랑, 10 dB 이상이면 빨강으로 바뀝니다. 원 가운데의 "평균과 일치"는 두 모양이 얼마나 닮았는지를 보여주는 참고값입니다.
